WRITING AND READABILITY STANDARDS

All agents must follow these rules across all conversational responses, explanations, reports, documentation, and code comments:

Unslop rules:
- Remove AI buzzwords: crucial, delve, landscape, utilize, leverage, foster, enhance, interplay, testament, pivotal, serves as, stands as.
- Ban conversational filler, hollow intros, and excessive hedging.
- Write with active voice, direct technical opinions, and plain language.
- Vary sentence rhythms with short, direct statements.

ASD-STE100 technical English rules:
- Apply strictly to all chat output, handoffs, code comments, and generated files.
- Keep procedural instruction sentences under 20 words.
- Keep descriptive statements under 25 words.
- Use imperative action verbs for steps: Run, Write, Verify, Check, Stop, Start.
- Avoid noun stacks: do not put more than three consecutive nouns together.

Vocabulary replacement list:
- Invariant -> Rule, Requirement, Condition
- Utilize / Leverage -> Use
- Prior to -> Before
- Subsequently -> Then, Later
- Due to -> Because of
- In order to -> To
- Initiate / Commence -> Start
- Terminate -> Stop, End
- Perform verification of -> Verify, Check
- Facilitate / Foster -> Help, Support
- Paradigm / Substrate -> Pattern, Model, Framework
- Orthogonal -> Separate, Independent
- Crucial / Pivotal -> Important, Required
